2026. 4. 13.

목차

    Beyond the Article: 한 걸음 더

    2026년에 알면 좋은 JS 지식

    https://frontendmasters.com/blog/what-to-know-in-javascript-2026-edition/

    JS의 신기능부터 시작해서 프레임워크/런타임/…까지 모든 생태계에 무슨 일이 있었는지 한 눈에 정리하는 글입니다. 너무 많은 정보와 신기술에 압도되었다면, 이 글을 보고 어떤 일이 있었는지 간단하게 보는 것이 좋아보입니다.

    React Native에서 JSI는 어떻게 동작하는가

    https://heartit.tech/react-native-jsi-deep-dive-part-1-the-runtime-you-never-see/

    React Native는 어떻게 동작하는가부터 시작해서 왜 JSI가 탄생했는지, 그리고 JSI를 실 환경에서 어떻게 사용되는지 보여주는 시리즈입니다. React Native 용어에 대한 간단한 소개를 보고 이 파트를 보면서 React Native가 어떻게 동작하는지 감을 잡으면 좋겠네요 🙂

    Axios 공급망 공격 사후 회고

    https://github.com/axios/axios/issues/10636

    이전 Axios 공급망 공격의 사후 회고 이슈입니다. 이전에 소개했듯이 pnpm으로 공급망 공격의 방화벽 세우기도 좋은 글이지만, 복잡하다고 생각된다면 설정 한 줄로 공급망 공격 최소화하기 글 또한 보는 것을 추천드립니다(다른 언어의 방어책도 소개합니다).

    useEffect 대신.

    https://neciudan.dev/you-really-really-dont-need-an-effect

    useEffect 대신 다른 패턴을 사용하는 것을 권장하는 글입니다. useSyncExternalStore은 다른 많은 부분까지 고려해야 하므로 다른 라이브러리 측에서 어떻게 사용하는지 보고(Tanstack Query, Tanstack Store, …) 자신의 상황에 맞게 사용하는 것을 추천드립니다.

    Straight to the Article: 빛나는 인사이트

    MDN의 React to Lit

    https://developer.mozilla.org/en-US/blog/mdn-front-end-deep-dive/

    MDN의 사이트를 React 기반 아키텍처에서 Web component기반인 Lit으로 바꿨고 왜 바꿨는지, 그리고 바꾸면서 만난 요구사항들을 어떻게 해결했는지 소개하는 글입니다.

    Github diff 화면 최적화

    https://github.blog/engineering/architecture-optimization/the-uphill-climb-of-making-diff-lines-performant/

    엄청 큰 내용이 보여져야 하는 경우 가상화 외에도 처리해야 하는 것들이 많다는 것을, 그리고 어떻게 해결했는지 간단하게 보여주는 글입니다. Github 재구성하기, RSC와 CSS로.도 같이 보시면 좋습니다.

    비동기를 취소하기 위해서

    https://www.inngest.com/blog/hanging-promises-for-control-flow

    비동기 workflow 함수를 취소 가능하도록 만들기 위해서 throw 방식과 generator 방식에 무슨 문제가 있는지, 그리고 이를 어떻게 구현해서 해결했는지 소개하는 글입니다. 단계적 실행이 필요한 경우 좋은 레퍼런스가 될 것 같네요.

    디자인 시스템의 기반은 환경이다

    https://zeroheight.com/blog/why-most-design-systems-fail-at-the-leadership-layer/

    디자인 시스템이 성공하려면 단순히 잘 만드는 것, 좋은 기술을 쓰는 것에 그치지 않고 환경을 구축하는 데에 있다는 간단한 글입니다.

    !important 쓰지 않기

    https://css-tricks.com/alternatives-to-the-important-keyword/

    !important이 왜 문제가 되는지, 그리고 최신 CSS를 포함해서 어떻게 !important를 줄일 수 있을지 소개하는 간단한 글입니다.

    Next.js에서 Proxy를 사용해서 동적 렌더링에서 벗어나기

    https://aurorascharff.no/posts/the-precompute-pattern-encoding-dynamic-data-into-urls-in-nextjs/

    Next.js의 cookies()나 headers()를 사용하면 하위 라우트가 모두 동적 렌더링이 되는 상황을 proxy를 사용한 패턴을 통해 해결할 수 있음을 보여주는 글입니다.

    Intl API로 i18n 포매팅하기

    https://polypane.app/blog/the-intl-api-the-best-browser-api-youre-not-using/

    Fresh Finds: 놓치지 말아야 할 소식

    https://boneyard.vercel.app/overview

    DOM에서 추출한 값을 기반으로 skeleton을 생성해주는 라이브러리인 boneyard입니다.

    https://www.bram.us/2026/04/02/view-transitions-toolkit/

    View Transition을 쉽게 사용할 수 있는 View Transition Toolkit입니다.

    https://tsdown.dev/options/exe

    rolldown 기반 간단한 번들러인 tsdown이 Node.js 기반 단일 실행 파일로 번들링하는 기능을 추가했다는 소식입니다.

    https://discourse.llvm.org/t/rfc-jsir-a-high-level-ir-for-javascript/90456

    JS환경에서는 AST/CFG 기반 오픈소스 도구들은 많은데 IR기반 도구들이 없기에 새로운 RFC를 통해 JS 기반 IR인 JSIR를 보여주는 글입니다.
