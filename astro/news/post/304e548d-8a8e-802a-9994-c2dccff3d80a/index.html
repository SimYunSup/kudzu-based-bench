    Beyond the Article: 한 걸음 더

    리액트 컴포넌트의 뉴노말

    https://shud.in/thoughts/build-bulletproof-react-components

    리액트 개발의 중심이라고 볼 수 있는 컴포넌트와 훅은 리액트 생태계의 인기 중심이 되었습니다. 하지만 리액트 훅과 API의 제한성, 다양화, 실행환경의 다양화… 여러가지를 고려해야 하는 상황이 되었습니다. 이 글이 모든 엣지케이스에 해결책을 제시해주진 않습니다. 하지만 useState가 아니라 상태와 친해지기와 같이, React API의 사용 방향이나 실행환경에 맞게 코드를 맞게 구성해야 한다는 것을 여러 방면에서 소개해줍니다.

    새로운 Rolldown, 어떻게 동작하는가

    https://www.atriiy.dev/blog/rolldown-high-performance-code-splitting

    Rolldown은 Rollup을 대체하기 위한 번들러입니다. 다른 번들러가 어떻게 동작하는지는 번들러마다 Tree shaking은 어떻게 다를까에서 보여주지만, Rolldown은 비교적 최신 라이브러리이기 때문에 정보가 부족합니다. 이 시리즈에서 모듈 스캔 단계, 의존성 트리 생성, 그리고 Code spliting(과 Tree shaking)을 소개합니다. 이 글에서 Rolldown이 무엇인지, 어떻게 동작하는지 소개합니다. 실제 Rust 코드와 심화 자료구조를 기반으로 소개하므로 어렵지만, 여러가지 장점과 동작방식을 자세히 설명하고 있으므로, 한 번 보시길 추천드립니다!

    React의 종료 애니메이션 문제

    https://barvian.me/react-exit-animations

    React에서는 기본적으로 transition class(ex. Vue의 <Transition>, Svelte의 transition:)를 제공하지 않았습니다. 그래서 react-transition-group라이브러리를 사용했어야 했는데, 이 블로그에서는 React의 <Suspense>와 훅을 이용해서 쉽게 구현하는 방식을 소개합니다.

    AI가 만드는 미래, 쉬운 파트는 더 쉬워지고, 어려운 파트는 더 어려워질 것.

    CSS 선택자의 다양화(2026)

    https://www.projectwallace.com/the-css-selection/2026

    CSS 선택자는 다양화 되었습니다. 그리고 CSS로 할 수 있는 파트는 매우 다양화되었습니다. 그렇지만 사용하고 있는 선택자와 문법은 제한되어있습니다. 이 글은 통계를 통해 어떤 기능을 사용하고 있는지, 어떤 과거의 잔재가 남아있는지 소개하고 있습니다. 어떤 새로운 유용한 기능이 있는지 분석하기에 좋으므로, 한 번 살펴보시길 추천드립니다.
