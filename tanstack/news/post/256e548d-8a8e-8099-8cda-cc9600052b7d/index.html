React cache, 그리고 데이터 일관성

https://twofoldframework.com/blog/react-cache-its-about-consistency

React의 cache()가 단순히 memo()의 확장된 버전, 최적화 방식이라고 생각할 수도 있겠지만, 더 많은 것을 제공합니다. 이 글은 cache로 감싼 경우의 데이터 일관성에 대해 알아보는 글입니다. 비슷하게, 동시성의 tearing 현상을 살펴보시려면, React 18에서의 상태 불일치 글을 참고하세요.
