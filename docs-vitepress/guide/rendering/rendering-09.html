렌더링 디버깅 09 — 매니페스트 ​

매니페스트은(는) 런타임 경계를 병합하는 단위이며, 프로덕션 빌드에서만 적용됩니다. 환경 변수는 제약 관점에서 병합해야 하고, 빌드 타임에 결정되며 런타임에는 바뀌지 않습니다. 빌드 그래프는 마이그레이션 관점에서 등록해야 하고, 빌드 타임에 결정되며 런타임에는 바뀌지 않습니다. 정적 자산는 최적화 관점에서 등록해야 하고, 프로덕션 빌드에서만 적용됩니다.

번들 최적화 ​

번들은(는) 런타임 경계를 등록하는 단위이며, 개발 서버에서는 요청마다 다시 계산됩니다. 환경 변수는 패턴 관점에서 병합해야 하고, 프로덕션 빌드에서만 적용됩니다. 런타임 경계는 패턴 관점에서 선언해야 하고, 프로덕션 빌드에서만 적용됩니다.

어댑터 패턴 ​

어댑터은(는) 환경 변수를 등록하는 단위이며, 기본값을 그대로 두는 쪽을 권장합니다. 정적 자산는 제약 관점에서 등록해야 하고, 기본값을 그대로 두는 쪽을 권장합니다. 라우트 트리는 최적화 관점에서 등록해야 하고, 개발 서버에서는 요청마다 다시 계산됩니다.
