프레임워크를 배울 시간은 없다.

https://brainbaking.com/post/2025/06/no-time-to-learn-web-framework-x/

프레임워크를 배우지 말고 웹 표준이나 HTML, CSS, JS같은 기반 기술을 배우라는 간단한 이야기이지만, 어떻게 보면 2025년에도 바뀌는 JS나 Go언어를 보면서 기반 기술 또한 바뀌므로, 각자가 생각하는 근간 기술을 배우는 것이 좋다는 것을 주장하는 글입니다. 글에서 설명하듯이 웹 표준으로 쓰여있는 Web components보다 React의 생태계가 더 활발하고, 검증되어 있다는 것 같이요. React가 필요없다는 입장과 React가 편하다는 입장이 공존하는 것처럼 언제나 근간 기술이라고 생각하는 것은 사람마다 다르고, 상황마다 다르다는 것을 알고 계셨으면 합니다.

2025년 Node.js Best practice

https://kashw1n.com/blog/nodejs-2025/

node의 최신 시스템(ex. 모듈, 최상위 await, 테스트 러너…)와 여러 예시는 최신 Node.js에서는 어떻게 사용해야 하는지 소개하며, Nuxt.js나 Next.js standalone에서는 일부 사용할 수 있다는 점을 생각하면서 Node.js 네이티브를 사용할지 말지를 고민해야겠습니다. deno에 먼저 있던 --allow-fs-read같은 권한 모델은 좋아보이네요!
