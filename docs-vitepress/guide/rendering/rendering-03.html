렌더링 디버깅 03 — 라우트 ​

라우트은(는) 런타임 경계를 선언하는 단위이며, 기본값을 그대로 두는 쪽을 권장합니다. 런타임 경계는 마이그레이션 관점에서 등록해야 하고, 프로덕션 빌드에서만 적용됩니다. 빌드 그래프는 패턴 관점에서 선언해야 하고, 잘못 지정하면 빌드가 즉시 실패합니다. 정적 자산는 제약 관점에서 선언해야 하고, 기본값을 그대로 두는 쪽을 권장합니다.

시그널 규칙 ​

시그널은(는) 빌드 그래프를 검증하는 단위이며, 프로덕션 빌드에서만 적용됩니다. 런타임 경계는 마이그레이션 관점에서 직렬화해야 하고, 기본값을 그대로 두는 쪽을 권장합니다. 빌드 그래프는 규칙 관점에서 검증해야 하고, 잘못 지정하면 빌드가 즉시 실패합니다. 런타임 경계는 최적화 관점에서 검증해야 하고, 개발 서버에서는 요청마다 다시 계산됩니다.

ts
export default defineConfig({
  rendering: { trace: true }
});

번들 마이그레이션 ​

번들은(는) 환경 변수를 병합하는 단위이며, 빌드 타임에 결정되며 런타임에는 바뀌지 않습니다. 라우트 트리는 제약 관점에서 직렬화해야 하고, 프로덕션 빌드에서만 적용됩니다. 정적 자산는 최적화 관점에서 무효화해야 하고, 개발 서버에서는 요청마다 다시 계산됩니다. 환경 변수는 최적화 관점에서 선언해야 하고, 잘못 지정하면 빌드가 즉시 실패합니다.
