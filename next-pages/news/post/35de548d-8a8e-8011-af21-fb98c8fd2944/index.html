Fresh Finds: 놓치지 말아야 할 소식

https://tanstack.com/blog/incident-followup

5월 11일, TanStack의 42개 패키지가 악성 코드가 심긴 채 npm에 재배포된 사고의 사후 대응을 다룬 리뷰 글입니다. 메인테이너가 피싱당하거나 토큰을 도난당한 게 아니라, 폐기된 fork PR이 트리거한 워크플로가 공유 CI 캐시를 오염시켰고, 이후 정상적인 main 병합의 릴리스 워크플로가 그 캐시를 복원하면서 러너 메모리에서 단명(short-lived) publish 토큰을 탈취당한 정교한 공격이었습니다.

https://voidzero.dev/posts/announcing-rolldown-1-0

고성능 JS 번들러 Rolldown이 1.0 stable로 프로덕션 레디가 되었다는 소식입니다. 속도, Rollup 플러그인 호환, 고유 기능을 갖췄고 최신 RC에서 코드 변경 없이 업그레이드된다고 합니다.

https://nodejs.org/en/blog/release/v26.0.0

Node.js 26이 출시되어 Temporal API가 기본 활성화되고, V8이 14.6(Upsert, Iterator.concat() 등)으로, Undici가 8.0으로 올라갔으며 http.writeHeader() 제거 등 정리가 이뤄졌다는 소식입니다. 10월에 LTS로 진입합니다.

https://tailwindcss.com/blog/tailwindcss-v4-3

Tailwind v4.3(과 블로그를 깜빡한 v4.2)이 스크롤바 유틸리티, @container-size, zoom-*·tab-* 유틸리티, stacked/compound @variant 지원, 신규 중립 팔레트(mauve·olive·mist·taupe), webpack 전용 플러그인 등을 추가했다는 소식입니다.

https://waku.gg/blog/waku-v1-beta

미니멀 React Server Components 프레임워크 Waku가 1.0 beta로, 재배포 시 이전 빌드 클라이언트가 깨지지 않는 version skew 처리, Vite 8 + Rolldown 빌드, CSP 지원, Node 26 지원을 갖췄다는 소식입니다.

https://github.blog/ai-and-ml/github-copilot/how-to-write-a-great-agents-md-lessons-from-over-2500-repositories/

GitHub이 2,500개 이상의 저장소를 분석해 효과적인 agents.md 작성법과 템플릿·실제 예시를 정리한 글입니다.
