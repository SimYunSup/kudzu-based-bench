2025. 11. 26.

Beyond the Article: 한 걸음 더

Tooltip은 정말 좋은 UX인가?

https://tkdodo.eu/blog/tooltip-components-should-not-exist

Tooltip을 잘 사용하는 방법과 비슷하게, 보통의 경우 tooltip을 사용하는 것이 UX를 해치며, 또한 구현 방법을 다르게, 혹은 사용하지 않는 것이 좋은 UX를 위한 것이라고 소개하는 글입니다. 비슷하게 Toast는 정말 좋은 UX인가?와 Github 디자인 시스템의 Toast deprecate 소식도 같이 보면 좋습니다.

e18e의 tinyglobby 성과 공유

https://e18e.dev/blog/tinyglobby-migration.html

JavaScript 생태계의 성능을 높이는 커뮤니티인 e18e에서 globby와 fast-glob을 대체하는 tinyglobby를 다른 라이브러리에 적용해서 어떤 성과를 냈는지, 다른 라이브러리와 비교해서 어떤 점이 좋은지 소개하는 글입니다. 만약 globby와 fast-glob를 아직도 사용하고 계신다면 tinyglobby를 고려해보세요.

디자인 시스템의 임팩트 측정하기

https://didoo.medium.com/measuring-the-impact-of-a-design-system-7f925af090f7

Uber의 디자인시스템의 사용량 측정 블로그와 비슷하게, 디자인시스템에 개발에서 개발에 가져다 준 임팩트를 어떻게 측정했고, 코드 변경 빈도가 어떻게 줄어들었는지로 임팩트를 소개하는 글입니다.

자바스크립트로만 동작하기는 어렵다.

https://pedrocattori.com/posts/just-javascript/

최근에는 JSX나, TypeScript같은 트랜스파일러나, 보이지 않는 기능들(HMR, 라우팅, …)으로 보여지는 자바스크립트로만 동작하기 어렵다는 간단한 에세이입니다. 우리가 사용하는데에 큰 문제는 없지만, 뒤에서 이러한 동작이 있고, 어떤 장단점을 가져오는지는 인지해야겠습니다.
